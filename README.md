# PANEL

安装：`npm install`

本地启动：`npm run dev`

生产构建：`npm run typecheck && npm run build`

Docker 启动：`docker compose up --build`，访问 http://localhost:3014。

## 声音模型

- 每个分镜记录自己的声景身份（`sound`）、切入方式（`transition`：延续 / 渐变 / 切断）与动作音效（`action`）。
- 同一声景在整本书内只有一条循环声轨：翻到同声景的分镜时只是继续，不会叠加；换声景时按分镜的切入方式淡出或切断旧轨。
- 动作音效归属于一次分镜访问。离开分镜、关闭声音或切换章节时会立即取消仍在播放或仍在解码的音效。
- 环境声、动作音效、对白压低幅度可在右侧面板分别调节；对白展开时环境声自动压低。
- 标签页隐藏或系统暂停音频后恢复，只重建当前分镜所需的声景与该分镜的音效，不补播离开期间错过的镜头。
